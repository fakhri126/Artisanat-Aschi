Architecture & Infrastructure

Guide d'Hébergement — Artisanat Aschi

Recommandations stratégiques, coûts, sécurité et plan de déploiement pour la mise en production.

1. Analyse de la Stack Technique

Votre application Artisanat Aschi est une plateforme e-commerce et vitrine d'artisanat de luxe composée de 4 éléments clés :

  • Frontend : Next.js 16 (React 19, TypeScript, Tailwind CSS, animations Framer Motion, configurateur catalogue).
  • Backend : Spring Boot 3+ (Java 17/21, API REST sous /api, sécurité JWT, port 8081).
  • Base de données : PostgreSQL (tables produits, catégories, devis, livraisons, avis, admin).
  • Médias & Vidéos : Photos HD de l'atelier, catalogue de poignées et vidéos/reels jusqu'à 500 Mo.

2. Les 2 Solutions d'Hébergement

⭐ OPTION 1 : Architecture Cloud Découplée (Recommandée à 100%)

0 € au début puis ~5 $/mois

Chaque brique est hébergée sur la plateforme spécialisée la plus performante au monde pour sa technologie, sans aucune gestion de serveur Linux.

1. Frontend Next.js ➔ Vercel (Gratuit)
Créateurs de Next.js. Vitesse de chargement mondiale via CDN Edge, SSL automatique, déploiement automatique via Git.
2. Backend Spring Boot ➔ Render / Railway (~5 $/mois)
Déploiement Java Maven automatique, redémarrage en cas d'incident, certificat HTTPS inclus.
3. PostgreSQL ➔ Neon.tech / Supabase (Gratuit)
Base PostgreSQL managée dans le cloud avec sauvegardes automatiques quotidiennes.
4. Photos & Vidéos ➔ Cloudinary / Supabase Storage
Streaming rapide des vidéos d'atelier et optimisation automatique des photos au format WebP/AVIF.

🥈 OPTION 2 : Serveur Dédié VPS Unique avec Docker

4,50 € à 6 € / mois fixe

Toute l'application (Frontend + Backend + PostgreSQL + Nginx) tourne sur une seule machine virtuelle Linux (Hetzner Cloud CX22 ou OVHcloud).

Avantages : Contrôle total, toutes les données et uploads sur le même disque dur, coût mensuel fixe et illimité en requêtes.
Inconvénients : Nécessite de maintenir le serveur Linux (mises à jour de sécurité, configuration Nginx et Certbot Let's Encrypt).

4. Checklist Technique pour le Déploiement

  1. Configuration CORS du Backend (SecurityConfig.java) :
    Remplacer http://localhost:3000 par votre domaine réel : https://artisanataschi.com.
  2. Variable d'environnement Frontend (.env.production) :
    Définir l'adresse de votre API backend : NEXT_PUBLIC_API_URL=https://api.artisanataschi.com/api.
  3. Nom de domaine & DNS :
    Faire pointer artisanataschi.com vers le Frontend et api.artisanataschi.com vers le Backend.
  4. Certificats SSL (HTTPS) :
    Automatique sur Vercel/Render ou via Certbot Let's Encrypt sur VPS.
