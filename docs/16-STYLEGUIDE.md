# Style Guide

## Charte Graphique (Luxury Design System)
- **Noyer Profond / Walnut** : `#1a1512` (Fond admin, modales)
- **Or / Gold** : `#C9A84C` (Boutons, bordures, liens actifs)
- **Bronze** : `#8C7853` (Sous-titres, survol)
- **Ivoire / Ivory** : `#FDFBF7` (Texte principal sur fond sombre)
